We present the result of using uncertainty to predict individual accuracy in \cref{table:appendix:exp:roc:u+ia}. 
This is similar to the practice of \citet{kuhn2023semantic,malinin2021uncertainty}.
Formally, this setting is $U(x)$ + Individual Accuracy: We use the uncertainty estimated on $m$ samples for each of the $m$ samples to predict each answer's accuracy.
For AUROC, this means
\begin{align}
        AUROC_{\text{U+IA}} &= \sum_{j=1}^m AUROC([-U(x_1), \ldots, -U(x_N)], [acc_{1,j},\ldots,acc_{N,j}]).
\end{align}
