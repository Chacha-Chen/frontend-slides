Motivation

LLMs are powerful — but when should we trust them?

  • High-stakes domains — medical QA, legal analysis, financial research
  • No ground truth at inference — we need signals from the model itself
  • Black-box reality — most frontier LLMs are API-only, no logit access

Key question: Can we quantify how uncertain an LLM is about its own response, using only its text output?

03
Background

Uncertainty vs. Confidence

Uncertainty

Property of the input distribution. Measures dispersion of all possible responses to input .

"Is this a hard question?"

Confidence

Property of a specific response. Measures how likely this particular answer is correct.

"Is this answer trustworthy?"

05
Methods

From Similarities to Uncertainty Scores

Num. Semantic Sets

Cluster responses by NLI entailment. More clusters = more uncertain. (Kuhn et al. 2023)

Graph Laplacian Eigenvalues

Build weighted similarity graph, compute . Continuous version of cluster count.

Degree & Eccentricity

Use node degree as confidence: well-connected responses are trustworthy. Spectral embedding gives per-response scores.

All methods work with only text output — no logits needed. NLI model is small and task-agnostic.

06
Results

Black-box UQ: Key Findings

  • Semantic dispersion outperforms white-box baselines — NLI-based measures beat sequence likelihood on AUROC across multiple LLMs and QA datasets
  • Confidence ≠ Uncertainty — per-response confidence (Degree) is more reliable than input-level uncertainty for predicting correctness
  • Simple measures work — graph degree with NLI similarity is competitive with sophisticated spectral methods

Practical takeaway: Even without logit access, sampling + NLI similarity gives reliable UQ for selective generation.

The Problem with Sequence Likelihood

When we do have logit access, the standard confidence score is:

But this conflates syntax and semantics:

Q: When did Neil Armstrong land on the Moon?
On July 20, 1969, Armstrong and Buzz Aldrin landed on the Moon for the first time in human history.

Not all tokens matter equally — the date is critical, "Buzz Aldrin" is irrelevant to the question.

08
Method

Contextualized Sequence Likelihood (CSL)

Re-weight token logits using the LLM's own attention mechanism:

How it works

  • Prompt LLM to evaluate its own response
  • Extract attention on response tokens
  • Select top-k heads via validation AUROC
  • Use attention as weights on token logits

Why it works

  • Attention focuses on semantically relevant tokens
  • Head ranking is stable (Spearman > 97%)
  • Transfers across datasets
  • Near-zero computational overhead

Summary

Two Complementary Perspectives on LLM Reliability

Black-box UQ (TMLR)

Sample multiple responses, measure semantic dispersion via NLI

Works with any API — GPT-4, Claude, Gemini

White-box CSL (ACL)

Re-weight logits with attention for context-aware confidence

Fast, no extra sampling, improves existing metrics

Both methods answer the same core question: "Should we trust this LLM output?"
This question becomes critical when LLMs move from generation to action.

Agentic UQ

Why UQ Matters More for Agents

Text Generation

  • Wrong answer → user ignores it
  • Cost of error: low (wasted time)
  • Human in the loop by default
  • Single-step, stateless

Agentic Workflows

  • Wrong action → irreversible side effects
  • Cost of error: high (data corruption, wrong trades, bad decisions)
  • Often autonomous / semi-supervised
  • Multi-step: errors compound

In agentic systems, UQ shifts from "nice to have" to mission-critical. An uncertain agent should ask for help, not guess.

Architecture

UQ as a First-Class Citizen in Agent Loops

LLM Reasoning
→
Tool Call (read PDF, query DB)
→
Interpret Result
→
UQ Check
↓
High confidence → Act
Medium → Seek more info
Low → Escalate to human
  • Per-step UQ — Each tool call and interpretation gets a confidence score
  • Adaptive routing — Uncertainty drives whether to proceed, retry, or escalate
  • Cascading confidence — Pipeline reliability = product of step reliabilities
13
Dimensions

Three Dimensions of Agentic Uncertainty

🧠

Epistemic

"I don't know this" — model lacks knowledge. Can be reduced with RAG, tool use, or better models.

📄

Grounding

"Did I read the document correctly?" — artifact parsing errors, OCR noise, ambiguous tables. Critical for document agents.

🎯

Planning

"Is this the right action?" — multi-step reasoning uncertainty. Wrong plan = cascading failures.

Existing UQ (my prior work) addresses epistemic uncertainty. Grounding and planning UQ are open research frontiers — and central to making artifact-understanding agents reliable.
